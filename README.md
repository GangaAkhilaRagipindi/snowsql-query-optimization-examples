# SnowSQL Query Optimization & Data Warehousing Examples

A collection of practical SnowSQL scripts showcasing cloud data warehousing patterns, performance optimization techniques, and automated pipeline features in Snowflake.

## Included Examples
1. **Window Functions & CTEs:** Ranking sales data per region using `ROW_NUMBER()` and `CTE` structures.
2. **Zero-Copy Cloning & Time Travel:** Quick sandbox table duplication and point-in-time recovery queries.
3. **Tasks & Streams (CDC):** Automated Change Data Capture pipeline using Snowflake Streams and Tasks with `MERGE` logic.

## Tech Stack
* **Language:** SQL / SnowSQL
* **Platform:** Snowflake
